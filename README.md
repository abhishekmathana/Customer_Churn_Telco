# Customer_Churn_Telco
This project analyzes customer churn behavior in a telecom company using Python (Pandas, Matplotlib, Seaborn). The goal is to identify key factors driving churn and provide actionable business insights.
## 📊 Dataset
- Total Customers: 7,043
- Features: 21 variables (demographics, services, billing, tenure)
- Target Variable: Churn (Yes/No)

---

## 🔍 Key Insights

- **Overall Churn Rate:** 26.54%
- **High-Risk Segment:** Month-to-month customers (~40–45% churn)
- **Low-Risk Segment:** 2-year contract customers (~2–5% churn)
- **Tenure Impact:** Customers <12 months have highest churn
- **Fiber Optic Users:** ~40%+ churn rate
- **Senior Citizens:** ~40% churn vs ~23% non-senior

---

## 📈 Key Findings

### 1. Contract Type
- Month-to-month → highest churn
- Long-term contracts → strong retention

### 2. Tenure
- Early-stage customers are most likely to churn

### 3. Service Adoption
- Customers without add-ons churn more
- Bundled services improve retention

### 4. Demographics
- Gender has no significant impact
- Senior citizens show higher churn

---

## 💡 Business Recommendations

- Improve onboarding for new customers
- Promote long-term contracts
- Bundle value-added services
- Optimize fiber optic service experience
- Target high-risk segments (new users, seniors)
